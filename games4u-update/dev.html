How do I get a token? (2 minutes, once)
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens and click Generate new token.
  2. Name it games4u. Under Repository access choose Only select repositories and pick your games4u repo.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy it, and paste it above. Each developer makes their own token. Never share it or put it in a file.
